# Preguntes freqüents (FAQ)

## Què és GreenLife?
GreenLife és una aplicació per gestionar el consum energètic.

## Com puc registrar el meu consum?
Pots introduir les dades manualment o connectar dispositius IoT.

## Les dades són segures?
Sí, utilitzem xifratge de punta a punta.
